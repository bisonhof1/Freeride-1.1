Freeride v1.1.0

Updated Freeride for SkateGM 9.0.

Changes

Updated keyboard controls for SkateGM 9.0 compatibility.

Kept the original Freeride movement system instead of SkateGM 9.0's new keyboard pushing controls.

Restored Mouse Flickit support.

Restored configurable Mouse Flickit deadzone.

Restored the experimental circular stick limit option.

Updated first-person camera support.

Restored Stabilized and Realistic First Person modes.

Restored Freecam.

Added/fixed configurable keyboard binds.

Camera mode can be cycled with B by default.

Freecam remains L by default.

Fixed Action 1 / Action 2 keyboard inputs.

Improved compatibility with SkateGM's current settings system.

Notes

Controller support for the first-person features is still untested, since I currently don't have a controller available for testing.

This version is made for SkateGM 9.0.
